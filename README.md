# hazmatcontrol

剧毒品/危化品仓库**双人同时在场核验 + 领用全过程监管**后台（Go，无第三方依赖）。

- 设计、威胁模型与现场难点对应关系见 **[DESIGN.md](DESIGN.md)**。
- 核心思想：把"双人同时在场"建模为随时间衰减、每次关键动作前重新求值的**持续租约**，而不是一次刷卡；把每条事件写成**签名哈希链 + 外置封印**，离线可用、可审计、可检测抹除/回滚。

## 快速开始

```bash
go test -race ./...      # 全部测试（含竞态检测）
go run ./cmd/demo        # 四类场景端到端演示
go run ./cmd/cabinetd    # 启动柜体控制器 HTTP API（默认 :8080）
```

## 包结构

| 包 | 职责 |
|---|---|
| `internal/presence` | 持续双人在场（在体感知、信号、重放、同体相关） |
| `internal/biometric` | 可弃权的生物特征融合（面罩场景） |
| `internal/access` | 双锁串行开启、槽位归属、开锁窗口、独立性证明 |
| `internal/weigh` | 皮重/稳定称重/分级容差对账 |
| `internal/session` | 领用状态机（每次取货前重新校验在场） |
| `internal/ledger` | 哈希链 + Ed25519 签名 + 封印 |
| `internal/edge` | 离线落盘、启动回滚检测、持久化发件箱 |
| `internal/hq` | 总部接收、回滚/分叉/断链检测、审计导出 |
| `internal/server` | 操作台与同步 HTTP 接口 |
| `internal/sim`, `cmd/*` | 模拟硬件栈与可运行程序 |

## 测试覆盖的攻防

- 工卡共享、串通后离开、开锁时序窗口、槽位冒充
- 面罩替代核验、照片攻击、弱证据拒绝、样本过期
- 超量硬中止、短缺转复核、不稳定/过期/换桶称重
- 账本改写/删除/重排/伪造、尾部截断、历史分叉、启动回滚
- 离线作业与断点续传
